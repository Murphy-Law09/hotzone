热区响 · 部署指南

全程手机操作，不需要电脑

一句话流程：注册 GitHub → 生成一个 token → 交给我 → 剩下的我全自动做完，APK 直接落到你手机上。

1注册 GitHub

  1. 浏览器打开 github.com/signup
  2. 填邮箱、密码、用户名（字母数字，比如 zhangsan2026）
  3. 完成邮箱验证

已经有账号就跳到下一步。

2生成 token

token 是一把临时钥匙，用来把代码推上去。用完就能删。

  1. 打开 github.com/settings/tokens
  2. 点 Generate new token → Generate new token (classic)
  3. Note 随便填，比如 hotzone
  4. Expiration 选 7 days
  5. 权限只勾 repo 这一个大类
  6. 拉到底点 Generate token
  7. 复制那串 ghp_ 开头的字符 —— 关掉页面就再也看不到了
安全：token 等于账号写权限。用完后请到 github.com/settings/tokens 把它删掉。 它会留在聊天记录里，删掉最保险。

3把 token 发给我

我在手机上直接跑脚本：

建仓库 → 上传全部代码 → 触发云端编译
→ 盯着编译 → 完成后自动下载 APK → 存到手机里

大概 3~6 分钟，你什么都不用做。

4装 APK

APK 会被我放到：

/sdcard/dsh/hotzone/dist/app-debug.apk

用文件管理器找到它，点安装。系统提示「未知来源」时选允许。

5第一次使用

  1. 打开「热区响」
  2. 点 授予悬浮窗权限 → 打开开关
  3. 回到应用点 启动热区（会弹一个通知，系统强制要求）
  4. 点 编辑布局：
    • 屏幕变暗，出现蓝色描边的圆圈
    • 拖动圆圈移动位置
    • 点空白处新增热区
    • 摆好后点 完成编辑
  5. 退出应用，热区还在 —— 切到微信、桌面，点那个位置就响

常见问题

点了没反应 / 看不见热区

运行模式下热区只有 6% 不透明度，本来就几乎看不见，这是设计如此。进编辑模式能看到描边。

过一会儿就不响了

被系统杀了后台。去 设置 → 电池 → 应用省电策略 → 选「无限制」。或者把「热区响」在最近任务里锁定。

通知栏一直有通知

删不掉。Android 规定前台服务必须有通知，否则不允许常驻。

想换音效

替换 app/src/main/assets/sound.mp3，保持文件名不变，重新推送一次。

GitHub 打不开

换个网络或流量试试。实在不行告诉我，我换成 Gitee 的构建方案（需要改一下 workflow）。

为什么不直接用 GitHub App

App 能做：看仓库、看编译状态、创建仓库。

App 不能做：生成 token（必须网页）、下载 Actions 里的产物（必须网页）。

所以网页至少要用一次 —— 就是生成 token 那一次。
下载 APK 那一步我已经替你自动化了，不用你去网页下载。
